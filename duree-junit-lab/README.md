# duree-junit-lab

TP Management de la Qualite Logicielle - Test unitaire JUnit 5 sur la classe Duree.

Ouvrir dans IntelliJ : File > Open > selectionner le dossier (ou pom.xml) > Open as Project.
Lancer les tests : clic droit sur DureeTest > Run 'DureeTest' with Coverage.
En ligne de commande : mvn test (rapport JaCoCo dans target/site/jacoco/index.html).
